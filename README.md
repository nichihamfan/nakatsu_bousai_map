# 中津市防災マップ（非公式・個人開発の試作版）

大分県中津市を対象エリアとした防災情報マップです。現在地表示・ハザードマップ（洪水／土砂災害／高潮／津波）の切替表示・標高の色分け表示・避難所270件の検索とルート案内・避難用品チェックリストなどを、**サーバー・外部アカウント・クラウドサービスを一切使わない静的サイト**として実装しています。

**本アプリは中津市が提供する公式サービスではなく、個人が独自に作成した非公式の試作版（PoC）です。** 実際の避難行動は必ず中津市の公式な防災情報・指示に従ってください。

## 主な機能

- **現在地表示・ルート案内**：GPSで現在地を取得し、最寄りの避難所までの徒歩ルートをブラウザ内で計算（外部の地図APIやルーティングサーバーは使用しない、道路網データを使ったDijkstra法によるクライアントサイド完結の実装）
- **住所検索・保存済み出発地**：GPSが使えない場合の代替として住所・施設名で地点を検索可能。複数の地点（自宅・職場等）を名前を付けて端末に保存し、起動時にワンタップで切り替えられる
- **ハザードマップの複数同時表示**：洪水・土砂災害・高潮・津波の4種類を任意の組み合わせで重ね表示
- **標高の色分け表示**：国土地理院の色別標高図を重畳し、ハザードマップの指定区域外でも低地には相対的にリスクがありうることを視覚的に確認できる（参考情報であり浸水想定そのものではない）
- **ハザード回避ルーティング（安全ルート）**：選択中のハザードエリアをできるだけ回避する経路を計算（ソフト回避方式）
- **気象庁の警報と連動したデフォルト表示**：起動時に現在地が気象庁の警報対象かつ該当ハザードエリア内にある場合、関連するハザードマップ・避難用品チェックリスト・受入可能な避難所を自動的に表示
- **避難所の受入状況表示・フィルタ**：開設・混雑・満杯の状況を色分け表示し、受入可能な避難所だけに絞り込み可能（サンプルデータ）
- **避難用品チェックリスト**：中津市公式資料に基づく61項目、世帯構成に応じた出し分け
- **多言語対応**：日本語／やさしい日本語／English／Bahasa Indonesia／Tiếng Việt／မြန်မာဘာသာ（ミャンマー語）の6言語
- **PWA・オフライン対応**：ホーム画面に追加可能。一度読み込んだ後はオフラインでも主要機能を利用できる
- **アクセシビリティ**：文字サイズ調整、色覚多様性に配慮した配色、キーボード操作対応

## アーキテクチャ

サーバー・データベース・外部APIキーを一切使わない、**静的ファイルのみで完結する構成**です。

- 地図表示・ハザードマップ・避難所検索・経路探索は全てブラウザ内（クライアントサイド）で完結します。
- 経路探索は、中津市全域の道路網データ（OpenStreetMap由来、約2.7MB）をJSONとして配信し、ブラウザ内のJavaScriptでDijkstra法を実行します。
- 利用している外部サービスはいずれも無料・登録不要の公開データです：国土地理院（地図タイル・標高タイル）、国土数値情報（ハザードデータ）、OpenStreetMap Nominatim（住所検索）、気象庁（警報・注意報API）。

## 動かし方

このリポジトリはビルド不要の静的サイトです。任意の静的ファイルサーバーで配信できます。

```bash
python3 -m http.server 8935
```

ブラウザで `http://localhost:8935` を開いてください。

## フォルダ構成

```
index.html            メイン画面
admin.html            避難所受入状況の更新ツール（内部向け、サーバー不要）
manifest.json         PWAマニフェスト
sw.js                 Service Worker（オフラインキャッシュ）
src/
  main.js              アプリ本体のロジック
  routing.js           ブラウザ内経路探索エンジン（Dijkstra法、外部依存なし）
  styles.css           スタイルシート
  i18n/                6言語分の翻訳ファイル
public/
  data/                避難所データ・受入状況・チェックリスト・道路網グラフ
  hazard/              ハザードレイヤー（GeoJSON、4種）
  icons/               PWAアイコン
scripts/               データ加工スクリプト（ジオコーディング・ハザードタグ付け・道路網グラフ生成等）
```

## 既知の制約

- 避難所の座標は中津市公式サイトの個別ページに埋め込まれた座標を利用していますが、設定時期・更新頻度は不明です。実運用にあたっては市への一次確認が必要です。
- ハザードデータのうち、ため池・内水（下水道能力を超える浸水）は、対応する全国標準のオープンデータが存在せず未収録です。
- 津波警報の自動連動機能は、津波予報区コードを座標から推定したベストエフォート実装であり、実際に警報が発表された際の検証はできていません。
- 受入状況データはデモ用のサンプルであり、実際の開設状況ではありません。

## ライセンス・データ出典

- 地図：国土地理院（地理院タイル）
- ハザードデータ：国土数値情報（国土交通省）
- 道路網データ：OpenStreetMap contributors（ODbL）
- 避難所データ：中津市防災ポータルサイト
- 気象警報データ：気象庁
